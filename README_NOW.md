# NOW — Android MVP

Local-first Android experiment for passive place sensing.

## V0.1
- Save current location as a monitored place
- 50–300 m detection radius
- ENTER / DWELL / EXIT events
- Local visit history
- Visit duration computed on EXIT
- No account, server, or cloud upload

## Android setup
Grant precise location. For passive detection while the app is closed, open App info → Permissions → Location → Allow all the time.
